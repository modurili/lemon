# 英単語ドリル (PWA)

モバイルファーストの英単語学習PWA。忘却曲線(SM-2簡易SRS)と習慣化支援に特化し、過度なゲーミフィケーションは入れていません。

## 公開(GitHub Pages)

1. このリポジトリをGitHubにpush (`master`/`main`)
2. `Settings → Pages → Build and deployment → Source: Deploy from a branch` を選択し、ブランチと `/(root)` を指定して保存
3. 表示されるURL(`https://<user>.github.io/<repo>/`)で公開されます(サブパス対応済・相対パスのみ使用)
4. スマホで開き、ヘッダーの **📲 アプリ化** ボタン (または共有→ホーム画面に追加) でインストール

ローカル確認: `python -m http.server 8000` → `http://localhost:8000/` (`file://`直開きではCSV fetchが制限されるためHTTPで開くこと)

## データ形式(CSVモジュール式)

ヘッダ(この順・日本語名で判定、無ければ列位置で読替):

```
連番,何詞か（名詞、動詞など）,英単語,訳,その他の訳をいくつかセミコロン区切りで,例文1,例文1の訳,例文1の何語目にその単語を使ったか,例文2,例文2の訳,例文2の何語目にその単語を使ったか,その英単語の由来や語源,その他備考あれば（類義語や対義語、名詞化や動詞化したものなど）
```

追加方法(どちらでも可):

- A. リポジトリ: `data/*.csv` を置き `data/manifest.json` の `decks` に `{id, file, title, enabled}` を追記
- B. アプリ内: 設定 → 教材管理 → CSVを取り込む (端末保存・有効化切替・削除・再書出可)

`例文Nの何語目` は2用途: 詳細画面の **ハイライト表示** と、文脈モードの **穴埋め出題**。詳細画面で切替可能。

## 学習仕様

- 出題: 認識(EN→JA自己評価) / 想起(JA→EN入力) / 文脈穴埋め。ミックス推奨
- SRS: Again/Hard/Good/Easyの4段階、Again=10分後、Hard≈1.2倍、Good=間隔×ease(初回1→3日)、Easy=さらに1.3倍、上限180日 (`js/srs.js` に分離、将来fsrs.js差替え可)
- 習慣化: 今日キュー=復習期限分+新規N語、1日目標(既定5語)、寛容型ストリーク(1日休みOK)、任意リマインド、発音TTS内蔵
- 保存: localStorageのみ(`etan.v1`)、サーバ送信なし。オフライン動作(SWキャッシュ)
